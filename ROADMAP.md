# Roadmap

This roadmap communicates direction, not delivery promises.

## Technical Preview entry

- Freeze a reviewable source baseline.
- Publish the API, web console, and deployment definitions together.
- Establish deterministic builds, required CI, dependency review, code scanning, SBOM generation, provenance, and signed images.
- Validate Redis and SurrealDB configuration for local and managed deployments.
- Document installation, configuration, backup, restore, and upgrade procedures.

## Preview hardening

- Publish an explicit OpenAI-compatibility matrix.
- Expand provider contract and failure-mode testing.
- Strengthen tenant, credential, and audit boundaries.
- Add clean-machine and upgrade-path verification.
- Define supported version and deprecation policies.

## Stable-release criteria

- Documented compatibility and migration guarantees.
- Repeatable security and release process.
- Operational guidance tested against supported deployment shapes.
- Maintainer capacity for issue triage, vulnerability response, and release support.

Track accepted work in GitHub issues. Items may be reordered or declined after design, security, maintenance, or licensing review.
