## What the AGPL-3.0 license does and does not grant

This project is licensed under the GNU Affero General Public License, version
3.0 only. Unlike Apache-2.0 — under which this project was previously
distributed, and whose Section 6 withheld trademark rights automatically — the
AGPL says nothing about trademarks in its main grant. It grants rights in
**copyright**, and copyright and trademark are separate bodies of law: a
license to copy, modify, and convey the code is not a license to use the name
it is published under.

Section 7(e) of the AGPL expressly permits a licensor to supplement the license
by "declining to grant rights under trademark law for use of some trade names,
trademarks, or service marks." **GaussMeridian exercises Section 7(e).** This
document is that supplementary term:

> No right or license is granted, by implication, estoppel, or otherwise, to
> the trade names, trademarks, service marks, or product names of this project
> — including "GaussMeridian" and any associated logos — other than the
> nominative and descriptive uses set out under "Acceptable use" below.

Two consequences worth stating plainly, because they differ from how permissive
licenses behave:

- Exercising your AGPL rights — forking, modifying, self-hosting, or offering
  the modified gateway as a network service — is fully permitted, and nothing
  in this document restricts it. What it does not do is give you the right to
  call the result "GaussMeridian."
- Because a Section 7(e) term is one of the additional terms the AGPL
  *enumerates as permitted*, it is not a "further restriction" that a
  downstream recipient may strip under the removal clause in Section 7. It
  travels with the code.

Section 7(e) is also why AGPL Section 13's source offer and this trademark
reservation coexist without conflict: you must hand your users the
Corresponding Source of your modified build, and you must not present that
build to them as the official GaussMeridian.

## Acceptable use

Generally acceptable, without separate permission:

- Referring to this project by name in blog posts, documentation, talks, or
  comparisons ("built on GaussMeridian", "compatible with GaussMeridian's
  API").
- Linking to this repository.
- Using the name in a factual, non-confusing way to describe an integration
  or a fork that clearly identifies itself as unofficial.

Generally **not** acceptable without prior written permission from the
project owner:

- Naming a fork, distribution, or commercial offering "GaussMeridian" (or a
  confusingly similar variant) in a way that implies it is the official
  project or is endorsed by it.
- Using the GaussMeridian name or logo in a way that suggests official
  affiliation, sponsorship, or endorsement where none exists.
- Using the name in a domain name, app-store listing, or company name in a
  way likely to confuse users about the source of the software.

## Retired name

This project was previously developed under the name "GaussRouter." That
name is retired and is not used for any current build, container image, or
release artifact. Runtime identifiers, container names, and published images
use the `gaussmeridian` prefix; the `gaussrouter-` prefix is treated as a
forbidden legacy identifier throughout this codebase's build and test
tooling, and should not be reintroduced by forks or derivatives claiming
compatibility with this project.
